JESSICA HUD — standalone Android / Samsung DeX

This native Java app does not use Unity, NRSDK or any XREAL SDK.
The IronManHUD_Clean Unity project is left untouched.

BUILD AND INSTALL
1. On GitHub, open Actions > Build Jessica DeX APK > Run workflow.
   The workflow must exist on the selected branch (manual dispatch is exposed
   once the workflow exists on the default branch).
   If a Copilot-triggered run shows "action required", approve it in GitHub
   before expecting a build or download. No APK exists until a run succeeds.
2. Open the completed run and download the Jessica-DeX-APK artifact.
3. Unzip it and copy app-debug.apk to your S23.
4. Open it on the phone and allow installation from that source if prompted.
   This is a debug-signed APK for personal testing, not a Play Store release.
   No Unity license, signing secret or provider API key is needed to build.

Local build: JDK 17, Android SDK platform 35 and build-tools 35.0.0.
From the dex-hud directory run:
  ./gradlew :app:lintDebug :app:assembleDebug
On Windows use gradlew.bat instead. Set ANDROID_HOME to your Android SDK.
Output: app/build/outputs/apk/debug/app-debug.apk
The same workflow packages the Windows x64 desktop HUD only after Android
lint/build succeeds. Its artifact is Jessica-Windows-x64; extract the whole
folder and launch JessicaHUD.exe. See desktop-hud/SETUP.txt for PC details.
PC packaging is independent of Unity; phone notification access is Android-only.

DEX AND CONTROLS
Connect the XREAL display to the S23, enter Samsung DeX, then open Jessica HUD
on the external display. Maximize the DeX window and use Fullscreen to hide
Android system bars where DeX allows it. Escape exits app fullscreen.
Use Samsung's "Use phone as touchpad" feature to click the visible controls;
this app does not implement a separate remote-control service.
The window is resizable and has no locked orientation. The control row scrolls
horizontally in small windows. Jessica's dialog supports typed input/keyboard.
Pause FX freezes reactor rotation but keeps the clock and battery updating.
Matrix switches the HUD to green; it is a visual theme, not AR immersion.
Customize selects cyan, green, amber or violet, HUD brightness, clock/battery
visibility and reactor animation. These customization settings survive restarts.
The layered reactor, radial ticks, core glow, scanning grid and FX bars are
decorative only; they are not measured suit/sensor telemetry.
Clock and battery are real. The reactor is fictional visual decoration.
No weather, hand tracking or eye tracking is implemented.

JESSICA / API PROVIDERS
The HUD works offline. For AI, open Jessica > Settings and enter your own
selected provider's API key on-device. OpenRouter, Groq and Cerebras connect
directly over HTTPS; no proxy or shared key is bundled.
The key is held only in memory, not written to
storage, logs, APKs or GitHub. Restarting or recreating the activity (including
some resize/orientation transitions) requires re-entering the key.
Provider, model and non-secret preferences are saved. Never commit a key.
Default model: openrouter/free (OpenRouter's free-model router).
Enter the provider key, then Browse available models to fetch its live catalog.
OpenRouter lists only free-named IDs with zero prompt/completion prices.
You can also enter a provider/model:free ID. OpenRouter paid IDs are rejected.
Groq and Cerebras catalog IDs are NOT a guarantee of free usage: their free
tiers depend on your account, limits and billing settings. Check your provider
dashboard; the app cannot enforce account quotas or guarantee no charges.
Free models still need an account/key; availability, quotas, provider terms
and account restrictions can change. No unlimited access is promised.
Changing providers clears the current chat so it is not silently forwarded to
another provider. Loading a saved chat requires confirmation before reuse.
Responses stream into the chat/HUD. Cancel stops local network work and polling;
it cannot recall data already submitted. Retry resends only the last failed or
cancelled prompt on explicit request; successful messages are not retried.

Send submits typed text. Voice opens the installed Android speech recognizer,
then sends the recognized question to Jessica. There is no always-on mic in
ordinary Jessica chat (Gemini Live is a separate opt-in session).
Using Voice during a text request cancels that request first.
Enable spoken replies in Settings to use Android text-to-speech. The chosen
system voice is used; a specific female voice is not guaranteed.
Speech recognition and TTS availability depend on installed engines/languages
and may use provider cloud services. Text input remains available if speech
recognition is missing. No raw audio is sent to OpenRouter by this app.
Local voice commands: "Jessica fullscreen", "Jessica matrix mode",
"Jessica cyan mode", "Jessica exit fullscreen", "Jessica pause effects",
"Jessica resume effects", "Jessica cancel request", "Jessica retry",
"Jessica new chat", "Jessica save chat", "Jessica open chat",
"Jessica customize HUD", "Jessica Gemini Live", "Jessica stop polling",
"Jessica stop speaking". Destructive commands still require confirmation.

SAVED CHATS / SEARCH / EXPORT
Saving is off by default. Enable local saved chats in Settings, then Save chat
to store a completed snapshot. Up to 10 snapshots are retained in private app
storage; they are not encrypted by the app and Android backup is disabled.
Saved / search filters the saved text, loads a selected chat after confirmation,
and offers Delete all. Turning off saved chats deletes stored snapshots.
New chat clears only the current in-memory chat. Chat context is bounded to
12 recent messages; the displayed/exported transcript is bounded to 16,000
characters. Snapshots include these bounded values, not a full unlimited log.
Export asks you to select a text-file destination using Android's document
picker. Exported files are outside the app's private storage and may be shared
or synced by the destination. Exports never include the app's configured keys.
Avoid putting sensitive information (including keys) in your chat text itself.

RIGHT-SIDE LIVE MESSAGE PANEL
Messages > Enable / access settings opts into Android notification access.
Enable Jessica live messages there and return to the HUD. New message-category
notifications appear on the right, newest first, on both HUD displays.
This uses notification events, not repeated SMS polling or SMS permissions.
Only message-category notifications with text are shown; apps that hide content
or use other notification categories may not appear. No historical inbox is read.
Android's access grant covers notifications broadly; the app filters to message
notifications and discards events unless the HUD activity is visible.
The latest four entries stay in memory only and clear when leaving the HUD.
They are never sent to any AI, saved with chats or included in chat exports.
Anyone viewing your phone/glasses can read them. Messages > Disable / clear
stops the panel; revoke notification access in Android Settings to remove the
system grant too. Background monitoring and automatic replies are not provided.

GEMINI LIVE / VISUAL VOICE SESSION
Open Gemini Live from the HUD (or say "Jessica Gemini Live"). This is a separate
real-time Gemini Developer API session, not OpenRouter chat or Android TTS.
Enter your own Google AI Studio key and a supported Live model. Default:
gemini-3.8-live. The model is editable because access and availability change.
Allow microphone permission, then explicitly press Start. The app sends mono
16 kHz PCM microphone audio to Google and plays returned 24 kHz PCM audio.
The visual panel shows live microphone/speaker activity, connection status and
transcription when the model supplies it. This does not show generated video,
camera frames or screen capture, and does not read the message panel.
Use headphones to reduce echo. Stop, leaving the screen, audio-focus loss,
connection errors or the 10-minute safety limit end the session and close audio.
There is no automatic reconnect. Re-enter the key to start another session.
Keys and the bounded Live transcript stay in memory only; the key input is
cleared on Start or leaving the screen. Live transcripts are not saved/exported
with ordinary Jessica chats. Google receives microphone audio during a session.
Google project/region/model quotas and billing apply: API access is not funded
by a Gemini app subscription or OpenRouter credits. Free usage is not guaranteed.
This personal-test client uses a user-entered key. A distributed production
client should use a backend-issued ephemeral token instead of bundling a key.

POLLING AND PRIVACY
Enter a text prompt, select Start polling and confirm. The prompt and recent
chat are sent after each reply with a 60-second delay. Polling never reads SMS,
notifications, clipboard, sensors or audio. It cannot supply live information
unless you type it in. Stop polling cancels future sends, not a request already
submitted. Errors stop polling rather than repeatedly retrying.
Leaving the app stops polling, cancels network work and stops speech; returning
does not restart polling. No background monitoring or autonomous actions.
The selected API provider and its model providers receive prompts/recent chat.
Chat is bounded and held only in memory unless you explicitly save or export.
Do not submit sensitive information.
AI output is untrusted and may be inaccurate; it cannot execute app commands.

DISPLAY LIMITATIONS
This is a conventional fullscreen Android display app, not spatially anchored
AR. Black reduces emitted light but does not hide the real world or provide
camera passthrough. System/window chrome depends on Samsung DeX.
Target device: S23 with Samsung DeX. Physical XREAL 1S compatibility must be
tested on your setup; this repository cannot certify display behavior.
Pixel desktop/external-display behavior needs separate testing; it isn't DeX.
PC-native support is not included.

PIXEL / SECONDARY-DISPLAY MODE
No DeX clone is necessary to display a single HUD app. Connect a supported
external display and open Display > select the glasses/display. Android's
Presentation API draws the HUD on the external screen, leaving controls and
Jessica chat on the phone. Live status, colors and animations update both.
Disconnecting the display dismisses its HUD; leaving the app also closes it.
Select Phone / current app window to stop the separate-screen HUD.
This is generic Android support, not a verified Pixel 10 Pro XL guarantee.
Android must expose a presentation-capable secondary display. The app cannot
force wired video output or turn a mirrored-only connection into a separate
display. If none appears, use the OS external desktop/mirroring mode and open
the app there, if supported by your phone/OS/cable/glasses combination.
